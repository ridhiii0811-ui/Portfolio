# Ritisha S. — Personal Portfolio

A student portfolio made with HTML, CSS and JavaScript.

## Run locally
Open index.html in a browser, or use the Live Server extension in VS Code.

## Files
- index.html — page content and sections
- style.css — styling and responsive layout
- script.js — dark mode, mobile navigation, active section link and form validation

The contact form is a front-end demonstration only; it does not send messages. Update the portfolio as you complete projects and earn certificates.
